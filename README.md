# CantoListo

Aplicación web para organizar repertorios musicales de músicos parroquiales.

## Funciones previstas

- Organizar cantos por celebración y tiempo litúrgico.
- Guardar títulos, tonos, instrumentos y notas.
- Crear listas de cantos para misas, retiros y adoración.
- Asociar archivos propios o autorizados.
- Acceder de forma privada a los datos de cada usuario.
